# Session: Internal Linking and Navigation


## Objective
Improve crawl paths and user discovery among existing eligible pages.

## Required work
- Homepage → featured match, competition sections and selected club pages.
- Selected club pages → upcoming approved matches and relevant competition pages.
- Match details → both team pages only if they are eligible; competition page when eligible.
- Competition pages → approved matches within that competition.
- Date pages → approved match pages and persistent matches hub.
- Review pagination and orphan pages using existing crawl/link data.
- Use descriptive natural Persian/English anchor text; no artificial links or giant link clouds.

## Acceptance criteria
Crawlable links, no broken internal URLs, no links that expose unapproved/noindex pages as key destinations, and mobile navigation remains usable.
