# Session: Competition Pages, Date Pages and Empty States


## Objective
Keep only useful competition/date landing pages indexable and make selected-fixture emptiness clear and helpful.

## Required work
- Indexable competition pages: five domestic leagues and Champions League by default, provided each has distinct useful content.
- Europa League, Conference League and domestic-cup pages only if meaningful content and current match coverage justify an indexable page.
- Do not generate thin pages for every competition.
- Preserve `/matches/tomorrow` as a permanent page; test empty, one-match and multiple-match states.
- Empty-state copy must say there is no selected high-priority match in SportSignal's current coverage, not that no football match exists globally.
- Audit `/matches/today`, `/matches/this-week`, `/matches/this-weekend`, date variants and pagination for duplicate/thin intent.

## Acceptance criteria
Correct canonical/indexability and empty state for Persian/English; no additional URLs for every calendar date; no false completeness claims.
