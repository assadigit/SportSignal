# Session: English SEO and Hreflang


## Objective
Improve English SEO in parallel without compromising Persian-first priorities.

## Required work
- Audit existing English URL set and language switcher before changing architecture.
- Preserve current URL pattern if technically sound. If no robust English structure exists, propose `/en/` with migration plan before implementation.
- Create natural English copy for equivalent pages; do not translate Persian literally.
- Add self-canonical and reciprocal hreflang for actual equivalent pages only.
- Ensure hreflang return links, valid language codes, canonical alignment and sitemap consistency.
- Do not publish English pages for non-selected teams or unsupported competitions.
- Use GSC countries/queries to evaluate English target geographies; do not assume a country.

## Acceptance criteria
Persian and English versions return correct canonical/hreflang, no absent alternate is referenced, English pages have distinct useful content, and sitemap consistency is verified.
