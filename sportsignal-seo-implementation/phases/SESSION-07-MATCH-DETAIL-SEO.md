# Session: Match Detail Template and Metadata


## Objective
Improve SEO for approved match pages while preserving the existing rich match-detail experience.

## Required work
- Audit current data fields and page content before writing copy.
- Ensure each approved match URL has unique title, H1, meta description and Open Graph data based on accurate teams, competition, date and final result when completed.
- Use natural Persian team-name aliases in body copy only where relevant; do not stuff all spelling variants into titles.
- Ensure match date/time and timezone are correct.
- Preserve useful content; no filler word-count expansion.
- Do not target live score, broadcast channel, lineup or minute-by-minute intent if unsupported.
- Make links to selected team and eligible competition pages consistent.

## Acceptance criteria
Representative fixtures (upcoming, completed, postponed/cancelled and exceptional non-selected match) render correct metadata, content and canonical. No new page generation for ordinary non-selected vs non-selected fixtures.
