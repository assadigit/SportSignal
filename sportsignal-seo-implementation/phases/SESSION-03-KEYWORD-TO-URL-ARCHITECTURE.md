# Session: Keyword-to-URL Mapping and SEO Architecture


## Objective
Convert the validated keyword research and repository audit into one approved mapping and implementation blueprint.

## Required work
- Select one primary keyword/intent cluster per canonical URL.
- Map homepage, today/tomorrow/this-week existing date routes, five domestic competition landing pages, UCL landing page, selected-team pages, and editorially approved match detail pages.
- Decide what existing routes should be indexable, noindex, redirect or removed based on evidence.
- Resolve overlap between `/matches`, `/matches/today`, `/matches/tomorrow`, `/matches/this-week`, `/matches/this-weekend`, pagination and query parameters.
- Create content/metadata map for Persian and English separately.
- Confirm no page is being created solely to target a keyword variant.

## Deliverables
- `seo-implementation/keyword-research/KEYWORD-TO-URL-MAP.md`
- `seo-implementation/architecture/INDEXABILITY-MATRIX.csv`
- `seo-implementation/architecture/ROUTE-AND-CANONICAL-PLAN.md`

## Acceptance criteria
Every indexable URL class has a clear purpose, target intent, owner rule and canonical strategy. Team and match eligibility follows the editorial allowlist/exception model. The plan is reviewed against existing routes before implementation.
