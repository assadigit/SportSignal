## 2) The design (what "calm" means, concretely)

Two retirements, two replacements — the strip's GEOMETRY, pills,
dismissal contract and language law all survive from v13.235:

1. **The 6-message 30s marquee → a ONE-message-at-a-time rotator.**
   `.ps-rot` is a `display:grid` stack (`grid-area:1/1`: every frame in
   the same cell; the row auto-sizes to the tallest frame → the strip
   never reflows between frames). Exactly one short message visible per
   4s slot of a 12s loop, driven by per-nth-child NEGATIVE
   `animation-delay`s (0s / −8s / −4s — each frame's on-slot is the
   first quarter of its own timeline, so the delays step backwards).
   Fade + 7px rise (~0.48s), centered; hover parks the loop. Pure CSS —
   no timers, works no-JS.
2. **The 37.9KB moving GIF → a pure-CSS signal mark.** The old chip's
   skin now carries the Telegram plane SVG floating ±1.2px over TWO ping
   rings half a phase apart. Every animation is `opacity`/`transform`
   only (compositor-only). The page loses **37.9KB and one request**
   (the gif file + its immutable `_headers` pin stay per the retention
   rule; nothing references it).
3. **The copies**: one idea per frame (news / channel / bot); ≤600px
   swaps `.ps-l` long copies for `.ps-s` short ones (no @handles on
   phones — measured: the longest short copy spans 134px in the 172px
   stage, one line). `.ps-sr` static summary carries the whole sentence
   for screen readers ONCE (the rotating stage is `aria-hidden` — a 4s
   aria-live would churn).
4. **Reduced motion**: the loop parks on frame 1 statically (opacity:1,
   no animation — the bundle's global `*{animation:none!important}` kill
   is honored) and the mark freezes.
