# S40 — the quiet plain rank number (v13.251-ranknum)

> Agents: read AGENTS.md in the repo root first, and follow it for this whole task.

**Date:** 2026-11-09 · **Status:** Done and verified live · **Spec:** `docs/specs/team-rank-indicator.md` §12

## The owner's directive

> "Fix the league-standing number that overlaps the club name on the match
> cards. Then make it low-key, because each card already has a lot of data
> (time, date, competition chip, stadium chip). … Show it as a quiet plain
> number in the same row as the club name. No circle, no border, no
> background, no icon."

## The root cause

The deployed-but-**never-pushed S39 round** ("v13.250-ranksup") had parked
the chip as an absolutely-positioned superscript at the PHYSICAL top-right
corner of the name box (`top:-8px;right:-8px`, one corner for both teams
and both directions) — **76/76 chips measured overlapping their name box
on the live page**, sitting on the first line of names like آرسنال and
منچستریونایتد and crowding the three-dot share menu's corner zone.

  the 8% size difference is carried by the regular weight + muted ink
  (the owner's "never below 11px" floor forces this pairing).

  for under a day; the retention rule only requires serving them).

  retention files (a live-verified look); the S39 superscript state no
  longer exists anywhere by design.
