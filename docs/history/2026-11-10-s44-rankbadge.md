## The S44.1 hotfix (ADR-006)

The FIRST deploy shipped a corner-mirror bug: the outer `.rankchip` carried
`direction:ltr`, so its `inset-inline-*` corner rules resolved against the
badge's own ltr instead of the page's rtl — both pills sat on the INNER
corners. Caught by the live post-deploy geometry verification (home
rightOverhang +27px). The fix moved the `ltr` to the inner `#N` span (the
approved structure). Because the buggy bytes had been published under
immutable pins, the fix shipped under fresh names per ADR-006 rename-on-edit:
`public-13.79.js` → `13.80.js`, `public-13.86.css` → `13.87.css`, SW v126.
The buggy-window files stay on disk riding default cache headers.
