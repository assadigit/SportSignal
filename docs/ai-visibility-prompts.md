# AI-Visibility Test Prompts (G-14)

**How to use this file (plain language):**
Once a month, open each assistant below, paste the prompts, and note whether
SportSignal (`sportsignal.ir`) is mentioned/cited and whether the information
is correct. It takes about 15 minutes. Copy the results table at the bottom.

Run the prompts in: **Google (AI Mode / AI Overviews), ChatGPT (with search),
Perplexity, Claude, Gemini, Copilot (Bing).**

Note: indexing a new site takes days to weeks. Missing citations in the first
months are normal. What matters is the trend.
