**Purpose:** Planning reference only  
**Display timezone:** `Asia/Baku`  
**Default coverage window:** 13:00–02:00, crossing midnight

The table below shows common or representative kickoff slots converted to Baku time. It is not a complete list of all fixtures, all seasons, or all scheduling exceptions. Exact kickoff time must always come from the fixture provider or competition organizer.

## 3. What the table does and does not mean

- It supports the default 13:00–02:00 Baku-time coverage recommendation for mainstream European club football.
- It does not prove a universal earliest or latest kickoff for every European country or division.
- It does not guarantee there are no matches between 02:00 and 13:00 Baku time.
- It does not replace official fixture data or per-competition regulations.
- “Summer” and “winter” refer to the source region's applicable local clock rules. Do not derive the conversion from the season label alone if the precise date and source timezone are available.

## 4. Operational recommendation

Use **13:00–02:00 Baku time** as the default recurring window for mainstream European football monitoring. For a requirement to cover every event supplied for every selected competition, ingest all returned fixtures and keep out-of-window events available. An optional wider buffer such as 12:00–03:00 may be used for special monitoring, but it is still not a mathematical guarantee of exhaustive European coverage.
